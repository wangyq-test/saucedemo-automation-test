# SauceDemo 电商网站自动化测试框架

基于 **Selenium + pytest** 的 Web UI 自动化测试项目，采用 **Page Object 设计模式**，覆盖 SauceDemo 电商网站的核心业务流程。

## 📋 项目简介

本项目针对电商网站 SauceDemo（https://www.saucedemo.com/）进行自动化测试，覆盖**登录、商品浏览、购物车、下单结算**四大核心模块，共 **21 个测试用例**，通过 pytest-html 生成可视化测试报告。

**被测系统：** SauceDemo 电商网站  
**测试类型：** Web UI 自动化测试  
**测试框架：** Selenium 4.x + pytest 9.x  
**设计模式：** Page Object Model (POM)  
**浏览器：** Microsoft Edge（可切换 Chrome / Firefox）
